Open this Flutter project. If platform folders are missing, run
`flutter create --platforms=android,ios,web .`, then `flutter pub get`.

Run and test the complete flow: first-launch animated splash, three onboarding
screens, home, How to Play, level map and all five spelling-pattern levels.

spelling validation, lives and pattern drawing. Fix SDK compatibility warnings
and any overflow at 360x800 and 412x915. Do not add a backend or replace the
project. Finally run `flutter build apk --release` and provide the exact APK
