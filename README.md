# Spell & Shape Quest

Animated Flutter spelling game for children with a first-launch splash,
three-page onboarding, home, tutorial, level map and five playable levels.

Levels: SHINE, HOUSE, CROWN, HEART and PLANT. Each correct spelling reveals a
hidden shape. The game includes three lives, undo, optional first-letter hint,
haptics, shake feedback, star scoring and a win animation.

## Run

```bash
flutter create --platforms=android,ios,web .
flutter pub get
flutter run
```

Build APK with `flutter build apk --release`.
